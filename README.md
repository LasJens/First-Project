# First-Project
Игра "Спасите Скуропата"

Описание функций:
1) Платформа
  - движение в четырех направлениях
  - отражение шарика
  - отражение от бортов

2) Шарик
  - отражение от платформы
  - отражение от бортов

3) Отражающий квадрат (розовый)
  - отражение шарика соприкосновении

4) Кнопка открытия ворот (зеленая)
  - открытие зеленых треугольных ворот в правом верхнем углу

5) Кнопка активации отражающего квадрата
  - активация Отражающего квадрата

6) Кнопка ускорения (черная)
  - ускорение шарика в 1.4 раза

7) Кнопка замедления (фиолетовая)
  - замедление шарика в 1.4 раза

8) Кнопка проигрыша + Лава (красное)
  - немедленное окончание игры
